    Investigations & analysis

    Type the values only. Standard reference ranges for the patient's age and sex are built in; results outside the range are flagged (L / H, LL / HH critical) and interpreted automatically. Panels appear for the tests billed on the invoice — tick “Show all tests” for others.

    Clinical summary

    Auto-draft only writes into empty boxes and marks clinical facts it cannot know with “[ ]”. The treating physician must review every field before signing.

    Itemized charges

    Amount = Qty × Unit price (calculated). Add a short justification per category — it appears in the report next to the charges.

    Settlement

    Report options & sign-off

    Import invoice text

    Open the itemized invoice PDF, select all text (Ctrl+A), copy, and paste it below. Lines that end with Qty · Unit price · Amount become line items; ALL-CAPS headings become categories. ICD-10 diagnosis lines are picked up too. Review the result afterwards.

    Sign

    Sign below with a mouse, finger or stylus — or upload a scanned signature.

    Save case file

    Case files contain confidential patient information. Protect the file with a password before emailing or copying it — it is encrypted with AES-256. A lost password cannot be recovered.

    Reference ranges (normal standards)
