    Investigations & analysis

    Type the values only. Standard reference ranges for the patient's age and sex are built in; results outside the range are flagged (L / H, LL / HH critical) and interpreted automatically. Calculated values (anion gap, osmolality, corrected calcium, eGFR, QTc…) fill in by themselves. Panels appear for the tests listed in the services — tick “Show all tests” for others.

    Radiology, imaging & cardiac diagnostics

    Every imaging and cardiac study listed in the services gets a structured report. Set each structure to Normal (the standard normal description is printed automatically) or Abnormal and type only the abnormal finding. ECG and echo measurements are entered with their reference ranges.

    Clinical summary

    Auto-draft only writes into empty boxes and marks clinical facts it cannot know with “[ ]”. The treating physician must review every field before signing.

    Services & procedures performed

    The services provided during the stay (imported from the hospital bill — no prices are kept). They decide which investigation panels and imaging reports appear above. Add the clinical indication per group; it is printed in the report.

    Report options & sign-off

    Import invoice text

    Open the itemized invoice PDF, select all text (Ctrl+A), copy, and paste it below. Service lines (code, dates, description, quantity) are imported without prices; ALL-CAPS headings become groups. ICD-10 diagnosis lines are picked up too. Review the result afterwards.

    Sign

    Sign below with a mouse, finger or stylus — or upload a scanned signature.

    Save case file

    Case files contain confidential patient information. Protect the file with a password before emailing or copying it — it is encrypted with AES-256. A lost password cannot be recovered.

    Reference ranges (normal standards)

    Grey values are the built-in standard intervals. Type a value only where your laboratory uses a different interval — it is saved in this browser and used for every patient. The highlighted rows apply to the current patient. Critical (LL/HH) thresholds use the default units.
